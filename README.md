# Drink Water Reminder

A small Python script that sends a desktop notification when it is time to drink water. It sends the first notification immediately, then repeats every hour.

## Requirements

- Python
- The `plyer` package
- Desktop notifications enabled by the operating system

## Setup

Install the dependency:

```powershell
python -m pip install -r requirements.txt
```

## Run

```powershell
python main.py
```

Stop the reminder with `Ctrl+C` in the terminal.
